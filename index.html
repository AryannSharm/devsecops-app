Security built into every release

Each control below is enforced by the pipeline or the cluster, not just described.

Vulnerability gate

Trivy scans every image. HIGH or CRITICAL findings stop the build before deployment.

Non-root runtime

The container runs as user 101, never as root.

Read-only filesystem

Files inside the running container cannot be modified.

Secrets outside the code

Credentials live in a Kubernetes Secret, not in the Git repository.

Restricted network

A network policy only accepts traffic from approved pods.

No cluster credentials

The pod receives no Kubernetes API token, limiting what an intruder could do.
